# cfprob
A command-line tool for providing Codeforces problem links.

## Usage
```
cfprob [tag] [rating]   for finding a problem with specific tag and rating
cfprob [rating]         for finding a problem with random tag and specific rating
cfprob [tag]            for finding a problem with specific tag and random rating
cfprob help             for showing this help message
```

## Valid Ratings
From `800` to `3200` in intervals of `100`.
